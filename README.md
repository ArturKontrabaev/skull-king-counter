# Skull King Counter 🏴‍☠️

Счётчик очков для карточной игры **Skull King** (классика + русалки, 10 раундов).
Веб-приложенька для телефона: открываешь за столом, заводишь игроков, по раундам вносишь
ставки и взятки, тапаешь бонусы — считает очки за раунд с расшифровкой «почему такой счёт»
и ведёт итоговый лидерборд + историю партии.

## Запуск
Статика, без сборки. Локально:

```
python3 -m http.server 8777
# открыть http://localhost:8777
```

Или положить на любой статический хостинг / GitHub Pages и открыть на телефоне
(добавляется на домашний экран иконкой, работает офлайн).

## Структура
- `scoring.js` — чистое ядро подсчёта (без DOM). Тесты: `node scoring.test.js`.
- `app.js` — UI + состояние (localStorage).
- `index.html`, `style.css` — вёрстка, mobile-first.
- `manifest.json`, `icons/` — PWA.

## Правила очков
- Угадал ненулевую ставку → +20 × ставка; промах → −10 × |ставка − взятки|.
- Ставка 0: угадал → +10 × номер раунда; не угадал → −10 × номер раунда.
- Бонусы (только при угаданной ставке): 14 +10, чёрная 14 +20, пират пойман Скалл Кингом +30,
  Скалл Кинг пойман русалкой +50. Настраиваются на экране ⚙️.
